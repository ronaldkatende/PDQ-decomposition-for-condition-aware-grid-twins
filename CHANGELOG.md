# Changelog

## 1.0.0 — publication reproducibility package

- Included the original paper result JSON, tables and figures without changing their values.
- Fixed the missing data-acquisition package and added release citation metadata.
- Added offline tests, an evidence verifier and file-integrity checks.
- Routed new experiment runs to `runs/` so published evidence cannot be overwritten by default.
- Removed machine-specific instructions and clarified how to rerun or inspect the study.
